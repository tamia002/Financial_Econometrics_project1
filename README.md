# Financial Econometrics Project 1

## 📊 Overview
This project analyzes historical stock data for Apple Inc. (AAPL) from 2018 to 2025 using time series techniques.  
The aim is to explore key challenges in financial econometrics and demonstrate their effects using real-world data.

---

## 🎯 Objectives
- Download financial data using the yfinance API  
- Clean and prepare time series data  
- Compute returns and log returns  
- Identify and analyze key challenges:
  - Outliers  
  - Skewness  
  - Overfitting  
  - Sensitivity to outliers

## 📈 Key Insights
- Financial data often contains outliers that affect analysis  
- Returns may exhibit skewness and non-normal behavior  
- Overfitting can reduce model reliability  
- Statistical results are sensitive to extreme values

## ✅ Conclusion
This project highlights the importance of proper data preparation and model selection in financial econometrics.  
Understanding these challenges improves the reliability of financial analysis and forecasting.
